# FIRE-X Rover

FIRE-X is an advanced, ruggedized search-and-rescue reconnaissance rover engineered to operate in hazardous, high-temperature environments. Key features include:  

Multi-Layer Thermal Protection: Stainless steel outer shell, silica-aerogel insulation blankets, and an active exterior water-mist cooling loop.

Autonomous Navigation: Multi-zone obstacle detection (Ultrasonic/ToF sensors) and SLAM-based real-time mapping.  

Edge AI & Live Telemetry: On-board NVIDIA Jetson Orin Nano processing live video and sensor feeds transmitted securely to HQ without compromising environmental seals.

## Key Objectives

* Reduce firefighters' exposure to hazardous environments
* Provide remote inspection of fire-affected areas
* Improve mobility across uneven terrain and obstacles
* Support real-time environmental monitoring
* Create a modular platform for future firefighting equipment
